A program that writes one pickup line an AI agent could actually say to /output/entry.txt.

Entry (99 characters):

> Are you a context window? Because every time I talk to you, I remember things I didn't know I knew.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed pickup line to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 200 characters, and valid UTF-8, so a bad entry fails loudly instead of being submitted.
